# App Mobile (React Native)

## O que é

Aplicativo móvel para iOS e Android desenvolvido com React Native + Expo. Um único código roda nas duas plataformas. Publicado na App Store e Google Play com a identidade visual do cliente.

## Para quem é indicado

- Empresas que já têm um sistema web e querem oferecer acesso mobile para equipe ou clientes
- Negócios com processo de campo (vendas externas, entregas, inspeções) que precisam de app offline-first
- Produtos digitais que querem aumentar engajamento com push notification

## Funcionalidades base incluídas

- Telas de autenticação (login, cadastro, recuperação de senha)
- Navegação por abas e drawers
- Integração com a API do sistema existente
- Push notifications (Firebase)
- Funcionamento offline básico (cache local)
- Publicação nas lojas (App Store + Google Play)

## Funcionalidades opcionais (sob consulta)

- Câmera / scanner de QR Code / código de barras
- Geolocalização e mapas
- Pagamento in-app (Stripe, Mercado Pago)
- Integração com hardware externo (impressora Bluetooth, etc.)
