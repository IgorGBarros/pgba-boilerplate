# Plataforma SaaS Multi-tenant

## O que é

Sistema web completo pronto para ser comercializado como serviço (SaaS). Inclui autenticação, multi-tenancy (cada cliente tem dados isolados), painel de administração, cobrança recorrente e módulos personalizados conforme o modelo de negócio do cliente.

## Para quem é indicado

- Empreendedores que querem lançar um produto digital para outros negócios
- Empresas que já têm um processo manual e querem transformar em produto escalável
- Startups que precisam de MVP robusto para validar mercado

## Funcionalidades base incluídas

- Autenticação completa (JWT, refresh token, troca de senha)
- Multi-tenancy com isolamento total de dados por cliente
- Painel de administração (Django Admin customizado)
- Gestão de usuários e permissões por perfil
- Módulo de assinaturas / planos (integração com gateway de pagamento)
- API REST documentada (Swagger/OpenAPI)
- Deploy em nuvem (configuração Docker + CI/CD)

## Módulos de domínio (personalizados por projeto)

O que diferencia um SaaS de outro são os módulos de negócio — estoque, CRM, agendamento, jurídico, saúde, etc. O custo e prazo variam conforme o escopo desses módulos.

## Investimento e prazo

- **Base (plataforma sem módulos de domínio)**: 80 a 100 horas → R$ 9.600 – R$ 12.000 | prazo: 25 a 30 dias úteis
- **Com módulos de domínio**: 200 a 300 horas → R$ 24.000 – R$ 36.000 | prazo: 60 a 90 dias úteis
- Projetos maiores têm orçamento por escopo fechado — solicitar reunião técnica

## Diferenciais

- Código-fonte entregue ao cliente
- Arquitetura preparada para crescimento (multi-tenant desde o design)
- Treinamento técnico para a equipe do cliente (4 horas)
- 60 dias de suporte pós-entrega incluso no plano completo
- Manutenção mensal opcional: a partir de R$ 2.400/mês
