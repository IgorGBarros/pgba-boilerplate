# Sistema de Gestão de Estoque

## O que é

Sistema web para controle de estoque, produtos, categorias, movimentações (entrada/saída), relatórios e alertas de estoque mínimo. Desenvolvido em React + Django, rodando na nuvem ou no servidor do cliente.

## Para quem é indicado

- Lojas físicas e e-commerces com gestão manual (planilha Excel) querendo automatizar
- Distribuidoras e atacadistas com múltiplos depósitos
- Empresas com equipe de compras que precisa de rastreabilidade

## Funcionalidades incluídas

- Cadastro de produtos com código, categoria, unidade e estoque mínimo
- Movimentações de entrada (compra, devolução) e saída (venda, perda)
- Relatório de posição de estoque em tempo real
- Alertas automáticos quando produto atingir estoque mínimo
- Controle de usuários com permissões por nível
- Histórico auditável de todas as movimentações
- Exportação em Excel/PDF

## Funcionalidades opcionais (sob consulta)

- Integração com leitor de código de barras / QR Code
- Integração com sistema de PDV (frente de caixa)
- App mobile para conferência de estoque
